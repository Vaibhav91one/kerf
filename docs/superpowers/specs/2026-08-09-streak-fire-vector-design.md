# Streak Fire Vector Illustration

## Purpose

Create one compact streak-fire illustration for Kerf's dark-mode product UI. It represents an active learning or contribution streak and must remain legible at icon scale.

## Visual design

- Canvas: 64 × 64 px, transparent background.
- Form: a rounded outer flame, smaller inner flame, and one restrained spark accent.
- Palette: warm orange-to-gold fills selected for strong contrast on the existing dark UI.
- Style: flat, premium, geometric, and consistent with the approved dark-mode illustration direction.
- Exclusions: no text, character face, photorealism, heavy shadows, or unrelated decorative elements.

## Figma construction

Build the illustration directly in the existing Figma Design file as editable vector paths. Group and name the layers clearly. Do not modify existing sample pages or unrelated frames.

## Acceptance criteria

The illustration reads immediately as a streak flame at 24, 32, and 64 px; its component paths remain editable; and it works on the product's dark surface without a surrounding tile.
