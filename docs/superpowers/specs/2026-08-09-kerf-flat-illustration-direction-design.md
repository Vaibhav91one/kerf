# Kerf flat-illustration platform direction

## Objective

Create a third, isolated Figma page named `02 — Flat Illustration Direction` in design file
`VdPEaCxSvkLqEKibE5qpRE`. The page will repeat the approved seven-section comparison structure while
replacing the three-dimensional Khagwal imagery with preset flat SVG scenes from unDraw.

The existing `Wireframes — low-fi`, `00 — Visual Direction Sample`, and
`01 — Light Platform Direction` pages remain unchanged. The FigJam architecture file and every
other Figma file also remain untouched.

## Approved direction

- Light-only, modern premium product-platform design.
- Preserve the Kerf light system: warm ivory canvas, white working surfaces, forest-green actions,
  restrained lime highlights, cyan live states, coral rework states, and SUSE typography.
- Use unDraw preset SVG artwork for all large illustrations. Do not generate, trace, or redraw
  illustration scenes.
- Recolor the primary editable unDraw accent to Kerf forest green or the relevant semantic accent.
- Keep original unDraw composition, proportions, and recognizable scene structure intact.
- Create premium depth through the surrounding interface stage—soft tonal panels, subtle borders,
  restrained shadows, and negative space—rather than adding pseudo-3D effects to the artwork.

## Why unDraw

unDraw provides a broad, visually coherent library of flat vector scenes that can be recolored to
match a brand and scaled without loss. Its license permits personal and commercial use,
modification, and distribution inside a product without attribution. The license excludes
redistributing the illustrations as a competing asset pack or using them for AI training; neither
activity is part of this work.

- Library: `https://undraw.co/illustrations`
- License: `https://undraw.co/license`

## Illustration rules

- All large scenes are original unDraw SVGs imported as editable vectors or source-preserving SVG
  frames.
- Source assets live in a provenance tray beside the presentation board.
- Imported source nodes use names such as `unDraw / Design components / Kerf green`.
- Section-level uses clone the source nodes so there is one traceable visual source per scene.
- Artwork may be scaled, positioned, cropped by a frame, or paired with UI copy.
- Artwork may not be redrawn, structurally altered, mixed with another illustration family, or
  presented as original Kerf illustration work.
- The editable accent can change to action green, cyan, or coral when the scene has a clear semantic
  role. Other original neutral and skin colors remain intact.
- UI icons never use illustration artwork.

## Page and section structure

The presentation board remains 1,600 px wide and contains seven vertically separated white
sections on the warm canvas.

### 01 — Brand premise

Use one large flat product-craft scene on a pale green stage with the Kerf value proposition,
primary action, and rework metric. The artwork should read as an editorial product illustration,
not a mascot or decorative sticker.

### 02 — Foundations

Repeat the semantic palette, SUSE type hierarchy, surface behavior, and accessibility logic. Add a
small specimen showing how unDraw SVGs inherit semantic accents without changing illustration
structure.

### 03 — Icon and illustration language

Retain the existing navigation icons, official Claude mark, tier crests, and achievement badges.
Replace the Khagwal library row with a labeled unDraw specimen row showing the selected flat scenes,
their semantic roles, and their accent variants.

### 04 — Component specimens

Retain the light buttons, inputs, metric cards, sidebar-07, and table patterns. Add one compact empty
or guidance card demonstrating the separation between a functional icon and an explanatory flat
scene.

### 05 — Home direction

Keep the dashboard information architecture and premium light surfaces. Replace isolated 3D objects
with a restrained flat practice or growth scene inside the recommended-session card and a compact
league-progress illustration treatment.

### 06 — Live direction

Keep the focused question layout, visible progress, optional Claude help, and privacy explanation.
Use flat timed-study or detailed-answer artwork only in the contextual side panel; the answer
controls remain purely functional.

### 07 — Honest empty state

Use a single confident flat planning or first-task scene as the hero. Retain the three-step setup
journey, one primary action, sample-path alternative, privacy explanation, and measurable-progress
language.

## Product and privacy constraints

- Rework ratio remains lower-is-better.
- Tiers and badges remain display-only and never influence ranking.
- Claude remains a source identity, never a tier or achievement.
- No prompts, transcripts, code, file contents, or personally identifying activity are shown or
  implied as retained data.
- Any comparative or percentile data remains anonymous.
