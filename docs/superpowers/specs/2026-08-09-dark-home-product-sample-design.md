# Dark Home Product Sample

## Goal

Convert the existing `01 / — Home` low-fidelity wireframe into one polished dark-mode product sample while preserving every existing wireframe and sample page. Create the supporting illustration as a reusable editable vector on the existing assets page.

## Figma scope

- Source: frame `16:4`, `01 / — Home (standing, live strip, badges)` on `Wireframes — low-fi`.
- Destination: new page `03 — Dark Product Sample / Home`.
- Asset destination: existing page `Assets — Streak Fire`.
- Do not modify the source wireframe, FigJam board, or unrelated Figma pages.

## Visual system

- Dark-only presentation using near-black canvas and sidebar surfaces, slightly lifted blue-gray cards, subtle borders, off-white primary text, and muted cool-gray secondary text.
- Use the existing streak orange, amber, and gold variables as the dominant accent family. Add only the minimum supporting semantic colors needed for status and chart differentiation.
- Use SUSE for interface typography and SUSE Mono for metric values, ratios, timestamps, and compact technical labels.
- Maintain restrained radius, border, and elevation choices so the interface feels premium, dense, and operational rather than decorative.
- Use one consistent rounded-stroke icon family with meaningful icons for navigation, metrics, badges, privacy, and actions.

## Screen composition

- Preserve the 1440 × 1200 desktop size and 260 px sidebar-07 shell.
- Keep all content and values grounded in the wireframe.
- Recompose the top area as a high-emphasis season hero containing the `0.167` ratio, Diamond tier, progression ladder, and the supporting illustration.
- Retain clear cards for streak and qualifying sessions.
- Retain live-session cards, badges, and standings with stronger hierarchy and polished interaction affordances.
- Keep privacy and display-only qualifications explicit in the interface.

## Illustration

Create `Illustration / Tier Momentum` as an editable vector asset. The image combines a faceted diamond, orbiting progress marks, and a restrained flame accent. It should feel native to the product, remain clear on a dark surface, and avoid emoji, photorealistic, or 3D styling.

## Acceptance criteria

- The source low-fi page remains unchanged.
- The new Home page is visually complete at 1440 × 1200 with no clipped or overlapping content.
- Text and important controls meet readable dark-mode contrast.
- Icons are consistent in stroke, sizing, and optical weight.
- The Tier Momentum asset is a reusable editable vector component on the assets page.
- Figma metadata confirms the expected page, frame, component, and named layer structure.
- Final screenshots show a coherent premium dark product screen and a clean standalone asset.
